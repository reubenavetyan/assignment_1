# 🎭 Mad Libs Story Generator
This is a simple Python Mad Libs game where you enter different words and the program creates a funny story.

# 📚 Stories
There are 3 story options:

🏥 Hospital Stay
🏕️ Camping Trip
🏰 Enchanted Castle

You can choose a story by entering 1, 2, or 3.

If you enter another number, the program randomly chooses a story for you.

# 🛠️ Made With
Python
random module
Functions
User input
if/elif/else statements

# ▶️ How to Run
Download or clone this repository.
Open the Python file.
Run it with Python: python3 main.py
Choose a story and answer the questions.
Enjoy your funny story! 😂

# 🎯 Goal
The goal of this project is to practice Python basics while making a fun interactive program.
